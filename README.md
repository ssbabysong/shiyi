# 拾遗

随手拾起的灵感。一本只属于你的灵感杂志，可以安装到手机主屏幕（PWA）。

**在线使用：** https://ssbabysong.github.io/shiyi/

## 功能

- 杂志式版面：报头与期号、封面故事、目录、按日期编排的正文、页码
- 五个栏目：札记、摘句、延伸阅读、色票、图像
- 图像自动提取五色色带，色票附 CMYK 参考值，点色块复制色值
- 「索引」页按标签列出页码，「漫游」随机翻开一页
- 「版权页」切换日间版 / 夜间版，导出与恢复合订本
- 在其他 App 里分享链接或文字到「拾遗」（Android 安装后可用）
- 浅色 / 深色 / 跟随系统
- 离线可用，数据保存在本机（IndexedDB），可导出 / 导入备份

## 安装到手机

- **iPhone：** 用 Safari 打开上面的地址 → 底部「分享」→「添加到主屏幕」
- **Android：** 用 Chrome 打开 → 菜单 →「安装应用」

## 开发

纯静态文件，无需构建：

```
python3 -m http.server 8000
```

然后打开 http://localhost:8000 。修改 `app.js` / `styles.css` 后，把 `sw.js` 里的 `VERSION` 加一，已安装的用户才能收到更新。
